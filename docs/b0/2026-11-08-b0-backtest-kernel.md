# B0.4 统一回测内核设计说明

> 日期：2026-11-08
> 代码：`backend/app/services/research_backtest.py`
> CLI：`scripts/backtest_research.py`
> 测试：`tests/test_research_backtest.py`（10 项）

---

## 1. 分层边界

| 层 | 本轮 | 说明 |
| --- | --- | --- |
| 第一层：信号研究 | ✅ | 只判断 T 日收盘后是否满足条件，以及之后的价格表现 |
| 第二层：成交模拟 | ✅ | T+1 开盘成交、停牌顺延、开盘涨停买不进、退出跌停不可验证、费用 |
| 第三层：组合回测 | ⛔ | 资金、仓位、持仓冲突、风险限制；本轮只留接口边界，不实现 |

本内核**不生成信号**。信号由策略提供器按生产口径生成（RPS、趋势模板、形态命中、板块→个股），
保证回测调用的就是线上那一份判定。

## 2. 成交与收益口径

### 2.1 入场

- 默认 `next_open`：T 日收盘出信号，**T+1 开盘价**成交；
- T+1 停牌：顺延到复牌后第一个有行情的交易日；超过 `max_entry_delay=5` 记 `suspended`；
- T+1 开盘价已在涨停板：记 `unbuyable`，**不计入可成交样本**；
- `entry="close"` 只作理论对照（信号在收盘后才成立，现实中最早只能次日开盘成交）。

### 2.2 退出

- 持有 h 个交易日（入场日算第 1 天）的收盘价；
- 退出日停牌：顺延，超过 `max_exit_delay=10` 记 `no_exit`；
- 退出日收盘跌停：记 `exit_limit_down`，**保留观察收益，但不计入可成交样本**；
- 数据末端未走完：记 `pending`。

### 2.3 收益

```
入场日收益 = 当日收盘 / 入场价 − 1
之后逐日   = ∏(1 + pct_chg/100)
毛收益     = (∏ − 1) × 100
净收益     = [(1 + 毛收益/100) × (1 − cost_bps/10000) − 1] × 100
```

- 用官方 `pct_chg` 复利，**不用原始收盘价比值**：除权除息不会造出假跳空；
- 入场日当天用 `收盘/开盘`，同一根 K 线内部同一基准；
- `cost_bps` 是**一次完整买卖往返**的总成本，按上述公式只扣一次，不重复扣。

### 2.4 基准

- 默认 `market`：同一入场日、同一退出日的**全市场等权**；
- 基准同样剔除「入场开盘涨停」与「退出日跌停」；
- 基准**不剔除** ST / 次新（代表市场，不代表可交易池）；报告里会写明；
- 可选 `index:000001.SH`：指数收盘→收盘（`index_daily` 没有开盘价），与个股 `next_open` 不完全同口径，报告会告警。

### 2.5 最大不利波动

`MAE` = 持有期内**收盘累计收益**的最小值。日线无法还原盘中最大回撤；报告固定提示这一点。

### 2.6 市场环境

用 `index_daily`（默认上证）的确定性规则：

| 环境 | 规则 |
| --- | --- |
| 进攻 | `close > MA20` 且 `MA20 > MA60` |
| 防守 | `close < MA60` |
| 震荡 | 其余 |
| 未知 | MA 不足 60 根 |

按**信号日**分组，不按入场日；这样回答「在什么市场环境里出的信号」。

## 3. 状态与统计

| 状态 | 是否计入观察样本 | 是否计入可成交样本 |
| --- | --- | --- |
| `ok` | 是 | 是 |
| `exit_limit_down` | 是 | 否 |
| `unbuyable` | 否 | 否 |
| `no_quote` | 否 | 否 |
| `suspended` | 否 | 否 |
| `no_exit` | 否 | 否 |
| `pending` | 否 | 否（数据末端，不编造） |
| `price_invalid` | 否 | 否 |

输出字段：

- 总信号数、观察样本数、可成交样本数、各状态计数；
- 均值、中位、正收益占比、负收益占比、分布桶（≤−10 / −10~−5 / −5~0 / 0~5 / 5~10 / >10）；
- 超额均值、超额中位、跑赢基准比例；
- 扣费后均值/中位；
- MAE 均值；
- 分市场环境的同口径统计。

## 4. 防未来函数

| 检查 | 实现 |
| --- | --- |
| 信号只用 T 日及以前 | 信号提供器只查 `<= T` 的 RPS / 形态命中 / 板块成员 |
| 入场不早于 T+1 | `_find_entry` 从 `signal_pos + 1` 开始 |
| 退出按交易日定位 | `TradeCalendar` 位置，不按行数 |
| 停牌不当中断 | 缺失行只在 `present` 里为 False，收益跳过（0 涨跌），两端必须有行 |
| 数据末端不补 | `pending` 不返回收益 |
| 可复现 | 同一数据版本、参数、日期，两次运行结果一致（测试覆盖） |

## 5. 已知局限

1. 没有退市股名单：结果标注为「现存股票样本研究」；
2. 日线无法确认「开盘涨停但盘中打开」等逐笔成交；
3. 停牌顺延后实际成交日与计划日不同，样本带 `entry_delay/exit_delay`；
4. 指数基准是收盘→收盘，与个股次日开盘成交不完全同口径；
5. 组合层（资金/仓位/持仓冲突）未实现；
6. 基准未剔除 ST / 次新，若要更严基准需在策略层限制股票池后重跑；
7. 新股：用「库内首次出现日」近似上市日，矩阵起点之前已上市的老股无法区分；只打 `new_listing` 标记，不自动排除；
8. 退市：没有退市日名单，`no_quote` 只能说明「矩阵里没有这只票」，不能区分退市、长期停牌与从未采集。

## 6. 测试覆盖

`tests/test_research_backtest.py`：

1. 次日开盘入场与同日退出收益；
2. 开盘涨停不可买；
