### 1.1 `wudao_wash2`「洗完 → 明天可进」（它的 `pattern_wash2.py`）

四段结构：样板日 → 启动日 → **今日洗盘** → 明天放量过「洗盘高」。

- **前置**：≥28 根；取 `sample = bars[-3]`、`start = bars[-2]`、`wash = bars[-1]`，
  `sample_prev_close = bars[-4].close`
- **启动日**（`is_start_bar`，与我们的 `_wudao_start` 同一组数字）：
  样板日成立 + `start.high > sample.high` + `start.close >= sample.high*0.98` +
  `start.vol_ratio >= 1.5` + `start.pct_chg > 0`
- **洗盘日**（`is_wash_bar`，按顺序，任一不满足即不命中）：
  1. `wash.low < start.low * 0.995` → 否（破启动低）
  2. `wash.close < sample.high * 0.98` → 否（掉下样板高）
  3. `abs(wash.pct_chg) > 3.0` → 否
  4. 实体（相对启动收盘）> 3.5 **且** `wash.pct_chg > 2` → 否（大阳续涨不像洗）
  5. `wash.close > start.close * 1.04` → 否（相对启动收涨过多）
- **关键位**：`watch_high = 洗盘日最高`（明天要过的线）、`start_low`（作废线）
- **排序权重**（它用 prefer）：`abs(wash_pct) <= 2 且 wash.volume/start.volume <= 1.05` → prefer 2，否则 1
  → 我们映射成分数梯度（干净洗盘分更高）
- **文案**：`phase_label="明天可进"`、`fit_label="金丹节奏·洗完"`、
  `action="今天不追；明天盘中放量过洗高再小仓"`；
  `plan_text="明天过洗高 X 小仓；破启动低 Y 作废"`
- 它的纪律原文③④：洗盘日**只观察记账**；缩量阴过洗高不算启动；破启动低或放量破样板高且收不回 → 作废

### 1.2 `pile_wash`「强达型」（它的 `pile_wash.py`）

多日结构（十几到几十个交易日）：堆量吸筹 → 放量拉升 → 缩量洗盘 →（洗完再启动）。
**≥50 根** bars，在近 55 根里滑窗找「放量拉升窗口」。

- **找拉升窗口**：宽度 `w ∈ {5,6,7,8,9,10,12}`，起点从第 8 根到末尾；前段 `pre = 窗口前 18 根`（不足 8 根跳过）；
  要求 `surge_ret(窗口最高/前基) >= 16` 且 `close_ret >= 10` 且 `vol_lift(窗口均量/前段均量) >= 1.35` 且
  `阳线数 >= max(2, w // 3)`；`close_pos < 0.55` 时打分 ×0.7
- **打分**（取最高分的窗口）：`score = surge_ret*0.45 + vol_lift*12 + close_ret*0.25 + 阳线数`；
  拉升后量比 `wr = 后 14 根均量 / 拉升段均量`：`wr <= 0.72` → `+18 + (0.72-wr)*20`，`wr <= 0.9` → `+6`；后段不足 4 根 ×0.85
- **堆量判定**：`pile_ratio = 堆量段均量 / 安静段均量 >= 1.25` 且 `pre_ret > -12` 且 `pre_range < 38`
- **洗盘判定**：`洗盘天数 >= 3`（超过 18 根只取前 18 根）；
  `wash_vol_ratio = 洗盘均量 / 拉升均量 <= 0.72`、`wash.close[-1] >= base*1.05`、
  `giveback < 0.62`、洗盘振幅 `(wash_high/wash_low - 1)*100 <= 28`
- **阶段**：全部满足 → `wash`（缩量洗盘中）；其中
  `close >= wash_high*0.97`（且 `vol_ratio >= 1.15`、`pct > 0`）或 `close > wash_high` → **`ready`（洗后可盯）**；
  `close > wash_high*1.18 且 ret_5 > 18` 或 `giveback > 0.75` → `gone`（已经主升完，**不买入**）；
  找不到拉升窗口 → 退到「纯堆量」分支（`ratio >= 1.35` 且 `-8 <= ret <= 18` 且 20 根振幅 `<= 32`）→ `pile`
- **我们的取舍**：只把 **`ready`（洗后可盯）** 与 **`wash`（缩量洗盘中）** 出成两个形态 key
  （`pile_wash_ready` / `pile_wash_wash`），`pile` / `surge` 是「观察、别动手」，不值当占一张卡片；
  `gone` 绝不出信号（它的纪律明确「不买」）
- **关键位**：`wash_high`（过它才进）、`wash_low`（放量跌破先走）
- ⚠️ 这条我们 2026-09-29 做过一版半成品、被撤掉等源码（草案与生产漂移过一次，回测数字会失真）——
  **这次直接照抄它的数字**，并写进 `patterns.py` 顶部阈值表

### 1.3 `huabao_early`「华宝早期」（它的 `huabao_early.py`）

更早的观察池：连阳 + 贴 5 日线 + 量由缩转放 + MACD 抬头。**≥30 根** bars。

- **先淘汰**：`ret_20 > 32` 或 `ret_5 > 22`（已主升完）；`ret_20 > 18 且 close >= high_20*0.97` 时，只有 `ret_20 > 25` 才淘汰
- **连阳**：至少 3 根（最多回看 8 根）；末日弱阴容忍条件 `pct > -2.2 且 vol_ratio <= 1.35`
- **贴 5 日线**（`_hug_ma5`）：`(low/ma5 - 1)*100 ∈ [-2.8, +3.2]`、`(close/ma5 - 1)*100 ∈ [0, +9.5]`；
  `upper > 0.45 且 pct < 4` → 否；`pct > 9.5` → 否
- **量由缩转放**（`_vol_wake`）：末根量比 `∈ [0.55, 4.2]`，且满足两者之一：
  ① 连阳前 5 日缩量（`min(vol_ratio) <= 0.95 且均值 <= 1.2`）；② 量上台阶（末日 ≥ 起日×1.05，或峰值 ≥ 起日×1.2，或末日 ≥1.2，或末 2 日均值 ≥ 首 2 日均值×1.08）
- **MACD**：`macd[-1] > -0.05`，且（`macd` 抬头 或（`macd[-1] > 0` 且不降））且 `dif[-1] >= dif[0]`
- **连阳形态**（`_similar_yang_days`）：平均涨幅 `∈ [0.4, 6.5]`、涨幅方差 `<= 18`、贴均天数 `>= max(2, 60%)`
- **资金流那一步先不做**：它用 `fund_flow.flow_on_dates`（大单/主力净额），我们用 iFinD DDE 逐股净流入、
  口径不同 → 第一阶段**只用日线条件**；缺资金流它本来就「不淘汰」，所以不引入偏差（要接资金流放进第二批）
- **关键位**：连阳段起点、`ma5`
- 它的纪律：**只进观察**，真正动手仍要等走出「明天盯 → 今天可买」

## 2. 第二批（可选）：单票阶段标签

它的 `ticket.py` + `pattern.py::classify_bars` 把任意一只票归到一个阶段（我们个股页现在没有这一层）：

| 标签 | 条件（按代码优先级） | 建议 |
| --- | --- | --- |
| 今天可买 `start` | 昨为样板 + 今高过昨高 + 今收 ≥ 昨高×0.98 + 量比 ≥1.5 + 收红 | 盘中过昨高小仓；收盘才看见别追 |
| 吵起来了 `diverge` | `vol >= 2.5` 且（上影 ≥0.25 或收盘位置 ≤0.7） | 只卖不加 |
| 像出货 `dump` | `vol >= 1.4` 且 `pct < 2` 且上影 ≥0.3 | 减仓走人 |
| 明天盯 `sample` | 样板日成立 | 今天不买，记今高 |
| 休息中 `digest` | `pct <= 0` 且 `vol <= 1.15` 且 `ret_5 >= 8` | 有仓看均价，没仓别抄 |
| 刚有人气 `wake` | `vol >= 1.2` 且（`pct >= 4` 或 `high_pct >= 6`）且非样板 | 记自选 |
| 没动静 `silent` | `vol < 0.85` | 不看 |
| 对不上 `unknown` | 其它 / K 线 <25 根 | 空仓 |

落点：个股页加一块「阶段判定」（标题 + 标签 + 一句动作建议 + 那句「量比 = 今量 ÷ 近 20 日均量」的口径说明）。

## 6. 口径纪律（搬的时候必须一起带过来）

- **量比一律 = 当日成交量 ÷ 近 20 日均量**，不与昨日比；两边成交量单位要一致（东财「手×100=股」）
- 价格判定一律用**前复权**序列；`pct_chg` 自己由收盘重算，避免与源字段口径混用
