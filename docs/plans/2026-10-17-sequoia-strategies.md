# 移植说明：海龟突破 / 均线放量金叉（Sequoia-X，2026-10-17）

本文记录新增的两个形态**怎么选股、为什么这么写、和邻居怎么分工**。代码在
`backend/app/services/patterns.py` 的 `_turtle_breakout` / `_ma_volume`，阈值在同文件
顶部的 `TURTLE_*` / `MA_VOLUME_*` 两段。

## 1. 来源与移植原则

- 上游：[sngyai/Sequoia-X](https://github.com/sngyai/Sequoia-X)，MIT。
  本次对齐的版本是 `444c0db`（2026-05-09）。
- 源文件：`sequoia_x/strategy/turtle_trade.py`（`TurtleTradeStrategy`）、
  `sequoia_x/strategy/ma_volume.py`（`MaVolumeStrategy`）。
- **判定条件与阈值逐条照搬**；改的只有输出形态与排序方式：
  - 上游输出「布尔名单 + 按流通市值降序」；本站统一输出 **0~100 分 + 关键位 + 明细**，
    由分数排序（全站所有形态同一套口径）。
  - 上游自带一套「读本地 baostock 库 + 飞书 webhook 路由」的脚手架，本站不搬 ——
    数据来自 `stock_daily`，推送走站内既有的复盘链路。
- 板块与样本关沿用本站统一规则（见第 4 节），不在形态内部另设。

## 2. 海龟突破（`turtle_breakout`，分组「突破」）

### 2.1 选股条件（四条同时成立）

1. **突破 20 日最高价**：`close[t] > max(high[t-20 : t])`
   —— 注意比的是**最高价**，不是收盘价；窗口不含当日。
2. **流动性过亿**：`amount[t] ≥ 1e8`（`stock_daily.amount` 单位是**元**）。
3. **实体阳线**：`close[t] > open[t]`。
4. **真涨**：`close[t] > close[t-1]`。

第 3、4 条是上游的「防诱多」条款：高开低走的大阴线即使盘中创了 20 日新高也不收，
避免把「冲高回落」当成突破。第 1 条用 high 而不是 close，是它与本站既有
`new_high`（比收盘）最本质的区别。

### 2.2 打分（必要条件通过后再排 0~100）

| 项 | 权重 | 映射 |
| --- | --- | --- |
| 成交额 | 20 | `gate(amount, 1e8, 5e8)`：1 亿得 0 分、5 亿及以上满分 |
| 量比（5 日） | 35 | `band(vol5, 1.0, 3.0, 8.0)`：1~3 倍为理想区间、中段最高，8 倍归零 |
| 突破幅度 | 30 | `band(excess, 0.5%, 3%, 10%)`：突破太多视为追高，10% 归零 |
| 当日涨幅 | 15 | `gate(pct, 0, 3%)`：涨得越实越靠前 |

- `gate(v, 门槛, 理想值)`：过门槛才开始给分，到理想值满分（单方向）。
- `band(v, 下沿, 上沿, 上限)`：推荐区间中心最高分、两端降到 80%，超出「上限」归零（双方向）。
- 关键位：`breakout` = 前 20 日最高价（图上画突破线用）。
- 明细：`excess`（突破幅度）、`vol_ratio`（5 日量比）、`amount_yi`（成交额，亿元）、
  `pct_chg`（当日涨幅，百分数）。

### 2.3 与相邻形态的分工

| 形态 | 突破对象 | 量能要求 | K 线要求 |
| --- | --- | --- | --- |
| `new_high` 创 N 日新高 | 前 N 日**收盘**最高 | 无 | 无 |
| `volume_breakout` 放量突破前高 | 60 日**收盘**前高 | 量比 ≥ 2（5 日） | 无 |
| `platform_breakout` 平台突破 | 30 日窄幅平台上沿 | 量比 ≥ 1.5 | 无 |
| **`turtle_breakout` 海龟突破** | **20 日最高价** | 无硬门槛（只影响分数） | **阳线 + 真涨** |

四者可以同日同时命中同一只票，含义不同，不合并。

### 2.4 与上游的差异

- 上游按**流通市值**降序出名单（为此还额外查一次 baostock）。本站不取流通市值，
  改为上面那张加权分 —— 名单顺序会不同，但**候选集合完全等价**（必要条件一样）；
  最终入库还要过本站 `MIN_SCORE = 50` 的及格线，见第 4 节。
- 上游用后复权价；本站是前复权序列（`build_bars` 按真实涨跌幅复利）。突破判定在两种
  复权口径下等价，只要同一只票内部一致。

## 3. 均线放量金叉（`ma_volume`，分组「趋势」）

### 3.1 选股条件（两条同时成立）

1. **MA5 今日上穿 MA20**：`ma5[t-1] < ma20[t-1]` 且 `ma5[t] > ma20[t]`
   —— 只认「今天刚穿」，不是「已经在上方」。
2. **放量**：`volume[t] ≥ 1.5 × mean(volume[t-19 : t+1])`

⚠️ 量比分母**含当日**（上游 `rolling(20).mean()` 的口径）。本站通用的
`_volume_ratio` 分母不含当日，两者不同，不要互换 —— 含当日会让门槛略难一点。

### 3.2 打分

| 项 | 权重 | 映射 |
| --- | --- | --- |
| 放量倍数 | 65 | `band(vol20, 1.5, 3.0, 8.0)`：1.5 倍刚够门槛，2.25 倍附近最高 |
| 金叉强度 | 35 | `gate((MA5-MA20)/MA20, 0, 2%)`：刚穿上去得分低，拉开 2% 满分 |

- 关键位：`support` = 当日 MA20（回踩参考）。
- 明细：`vol_ratio_20`（20 日量比）、`cross_gap`（MA5 高出 MA20 的幅度）。

### 3.3 与相邻形态的分工

- `ma_golden_cross` 金叉共振：看 **MA5 × MA10**，要求 MA20 不走弱，语义是
  「短周期刚转强」；不要求放量。
- `ma_bull` 均线多头排列：MA5>MA10>MA20>MA60 且四线向上，语义是「趋势已经成型」。
- **`ma_volume` 均线放量金叉**：看 **MA5 × MA20** + **放量**，语义是
  「中期趋势切换 + 量能确认」。三者可以同日同时命中，不合并。

## 4. 全站统一口径（两个形态都适用）

- **输入序列**：`build_bars` 产出的**前复权**日线。除权跳空不会在错误位置触发突破。
- **样本过滤**：ST（名称含 `ST`）不参与；板块为**主板 + 创业板 + 科创板**
  （`is_pattern_board`，不含北交所）。这两个形态**不在** `WUDAO_POOL_KEYS` 里，
  所以不像悟道六池那样只收 20cm。
- **入库门槛**：`MIN_SCORE = 50`。必要条件通过只代表「有资格打分」，**分数不到 50 不入库**
  —— 所以页面上的命中是「条件成立且得分达标」，比上游的布尔名单略严。
- **执行时机**：每个交易日收盘后的 `scan_patterns.scan()` 全市场扫描；重扫幂等
  （整段替换该日命中）。形态数 51 → 53。

## 5. 参数一览

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `TURTLE_WINDOW` | 20 | 突破窗口（前 N 根的最高价） |
| `TURTLE_MIN_AMOUNT` | 1e8 | 成交额门槛（元） |
| `TURTLE_AMOUNT_IDEAL` | 5e8 | 流动性满分线 |
| `TURTLE_VOL_IDEAL` | (1.0, 3.0) | 量比理想区间 |
| `TURTLE_VOL_CAP` | 8.0 | 量比归零点 |
| `TURTLE_EXCESS_IDEAL` | (0.005, 0.03) | 突破幅度理想区间 |
| `TURTLE_EXCESS_CAP` | 0.10 | 突破幅度归零点（追高） |
| `MA_VOLUME_FAST` / `SLOW` | 5 / 20 | 快慢均线 |
| `MA_VOLUME_MIN_MULT` | 1.5 | 放量门槛（分母含当日） |
| `MA_VOLUME_IDEAL_MULT` | 3.0 | 放量理想值 |
| `MA_VOLUME_CAP_MULT` | 8.0 | 放量归零点 |
| `MA_VOLUME_GAP_IDEAL` | 0.02 | 金叉强度满分线（MA5 高出 MA20 2%） |

## 6. 前端展示

- 形态页筛选条自动出现「海龟突破」「均线放量金叉」（目录由 `/api/patterns/catalog` 返回）。
- 明细标签在 `frontend/src/pages/Patterns.tsx` 的 `DETAIL_FIELDS`：新增
  `amount_yi`（成交额(亿)）与 `cross_gap`（金叉幅度）；其余字段复用既有标签
  （`vol_ratio` 量比、`vol_ratio_20` 量比(20日)、`excess` 突破幅度、`pct_chg` 当日涨幅）。

## 7. 验证记录

- **本地冒烟**（本机库，日线到 2026-10-09，按代码顺序取 400 只、实际可判 392 只）：
  海龟突破 7 只、均线放量金叉 2 只 —— 频率量级与既有形态相当，没有「一天几百只」的失控。
- **线上重扫 2026-10-16**（全市场 5051 只，剔 ST 122 只）：**海龟突破 36 条、
  均线放量金叉 18 条**（约 0.7% / 0.36%），其余形态命中数不变；耗时 58.9 秒。
- 校验：`ruff` / `compileall` / `check_api_contract.py`（17 项）/ `npm run build` 全过。

## 8. 已知局限

- **尚未做全量历史回测**（`scripts/backtest_patterns.py` 可单跑
  `--pattern turtle_breakout` / `--pattern ma_volume`）。在有回测数字之前，
  这两个形态的定位与其它形状类形态一致：**按形状捞一批票自己看，不是买点信号**。
- 海龟突破的「成交额过亿」在缩量市里会显著减少命中（成交额不足 1 亿的票直接排除），
  这是上游的原始设计，没有放宽。
- 均线放量金叉要求「今天刚穿」，信号只出现一天；错过当天的扫描不会在次日补回。
