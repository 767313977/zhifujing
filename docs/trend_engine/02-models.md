# Trend Engine 双模型设计（V1.0）

- 代码：`backend/app/services/trend_engine/`
- Model A：`breakout_model.py`（`A-1.0.0`）
- Model B：`continuation_model.py`（`B-1.0.0`）
- 两个模型**独立评分、独立排序、独立回测**，不合成单一总分。

## 1. 统一评分规则

- 基础分项（结构 / 突破或回调 / 量价）在扣除卫星项后归一化到 100；
- RPS：默认 **3 分**，可配置 0～5，**不做硬过滤**；
- 板块：默认 **0 分**，可配置 0～5，**不做硬过滤**（B1 报告：板块叠加为负超额）；
- 分项缺失按 0 分计入并写进 `missing`；核心数据缺失直接 `eligible=False`；
- 硬性排除与评分分离：`exclusions` 非空时 `score=0`，不参与排名。

权重实现：`config.effective_weights(base, rps_points, sector_points)`，
例如 Model A 基础 40/30/30、RPS=3、板块=0 → 38.8 / 29.1 / 29.1 / 3.0。

## 2. Model A（趋势启动）

### 2.1 硬性排除

ST、北交所、日线不足 130 根、目标日无 K 线、20 日均额 < 5000 万、
平台窗口不足 / 停牌占比 >10%、平台宽度 >18%、未突破平台高点、
突破过度偏离（>8%）、收盘低于 MA20、MA20 向下、距 MA20 >15%、
突破日未放量（<1.5×）、收盘位置 <0.6、上影线 >50%、量价背离、
单日脉冲且收盘回落、高位连续加速。

### 2.2 分项（0～1）

| 分项 | 权重 | 组成 |
| --- | ---: | --- |
| structure | 40 | 收盘>MA20 (0.25)、MA20 向上/走平 (0.25)、MA60 不向下 (0.15)、MA20>MA60 (0.15)、趋势天数 (0.10)、均线收敛 (0.10) |
| breakout | 30 | 平台宽度 (0.35)、突破幅度 (0.25)、收盘位置 (0.25)、平台长度 (0.15) |
| volume | 30 | 成交额比 (0.40)、5/20 日量能趋势 (0.20)、涨跌量能比 (0.20)、收盘位置 (0.20) |
| rps | 3 | RPS20 40% + RPS60 40% + RPS120 20% |
| sector | 0 | 板块 RPS20 / 100（默认关闭） |

### 2.3 分层

80～100 重点启动候选 / 70～79 启动观察 / 60～69 等待确认 / <60 不进入核心池。

### 2.4 平台与突破的 PIT 约束

- 平台高/低点窗口**不含当日**（`high[-days-1:-1]`，或按 `trade_days` 切片）；
- 平台期停牌覆盖 <90% → 直接排除；
- 只做**收盘确认**：盘中突破不产生信号。

## 3. Model B（趋势延续）

### 3.1 硬性排除

ST、北交所、数据不足、流动性不足、MA20 ≤ MA60、MA20 向下、
收盘低于 MA20 超过 3%、站上 MA20 天数 <20、回撤 <3% 或 >12%、
高位放量滞涨；`MA60 向下` / `MA60 ≤ MA120` 属于**例外标记**（可配置为硬排除）。

### 3.2 回调结构

- 在最近 60 个交易日里找「最近一次已完成的回撤」：以运行最高点为基准，
  取最大回撤日为谷，峰为谷之前的最高收盘；
- 回撤深度、ATR 标准化回撤（深度 / ATR%）、回调期量能 / 上涨期量能、
  回调低点相对当时 MA20、支撑价 = max(谷, 当时 MA20)、再次转强确认。

### 3.3 分项（0～1）

| 分项 | 权重 | 组成 |
| --- | ---: | --- |
| structure | 40 | MA20>MA60 (0.25)、MA60>MA120 (0.15)、MA20 向上 (0.20)、MA60 向上/走平 (0.15)、趋势天数 (0.15)、收盘>MA20 (0.10) |
| pullback | 30 | 深度区间 (0.25)、ATR 标准化 (0.25)、缩量 (0.20)、支撑 (0.20)、再次转强 (0.10) |
| volume | 30 | 成交额比 (0.25)、量能趋势 (0.20)、涨跌量能比 (0.20)、收盘位置 (0.15)、无背离 (0.20) |
| rps | 3 | RPS60 45% + RPS120 35% + RPS250 20% |
| sector | 0 | 同 Model A |

### 3.4 分层

85～100 核心趋势观察 / 75～84 趋势延续候选 / 65～74 等待确认 / <65 不进入核心池。

## 4. 风险引擎

- 状态：`NORMAL / WARNING / BROKEN`；数据不足为 `UNKNOWN`（未知不是低风险）。
- BROKEN 需 ≥2 个核心条件同时成立（连续 2 日跌破均线、MA20<MA60、
  跌破结构低点、异常跳空与均线条件叠加）；单日跌破只升 WARNING。
- Model A 锚：MA20 / 平台低点；Model B 锚：MA60 / 40 日结构低点。
- 输出：状态、起始日、失效参考价、ATR 风险价、结构低点、复核日期、
  风险原因、是否建议降低关注级别。
