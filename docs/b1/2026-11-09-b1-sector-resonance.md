# B1.3 板块与个股共振验证

> 日期：2026-11-09
> 脚本：`scripts/validate_sector_resonance.py`
> 数据：`b1_research.db`；60 日 `sector_member`（每日强度前 40 个精选板块，2,420 board-day complete）
> 证据：`backend/data/b1_sector_resonance.json`（未提交）
> 结论：**没有证据表明「强势板块过滤」能改善个股表现；B/C 组在 5/10/20 日反而更差。**

---

- **40/60 日板块共振：证据不足，不可判断**；
- 不能因为 5/10/20 日 B/C 更差，就反推「长期会更好」；也不能用 5 个日期的 60 日结果下结论。

## 4. 公平性与对照

| 检查 | 结果 |
| --- | --- |
| 同日信号 | A~E 使用同一批信号日（B/C/D 是子集） |
| 同价格规则 | 全部 T+1 开盘、同停牌/涨跌停规则 |
| 同费用 | 0 bps |
| 同基准 | 全市场等权 + 所属板块等权 |
| 多板块重复计数 | 每只股票每个信号日只计一次；B/C/D 任一板块满足 |
| 板块归属时点 | 用信号日 `sector_member`，不是当前成分 |
| 板块强度时点 | 只用到信号日及以前的 `sector_daily` |
| 板块对照 | 所属最强板块等权，能区分「个股强」与「板块整体涨」 |

## 5. 结论

**没有证据支持「强势板块 + 强势个股」会更好。**

- B/C 组（强板块/持续强板块过滤）在 5/10/20 日**比不加过滤更差**；
- D 组（板块 RPS 改善）相对不那么差，但绝对收益仍为负，不能作为买入依据；
- E 组（板块排序辅助）与 A 基本一致，没有增量；
- 个股平均跑输所属最强板块，说明「板块强」没有传导为「个股超额」；
- 40/60 日有效日期不足，**不可判断**。

**建议**：板块强度更适合作为**研究背景/风险变量**（例如解释为什么某些行业整体回撤），而不是硬性选股过滤；不应在 P0 页面把「热门板块」直接包装成「共振买点」。

---

## 6. 限制

1. 只回补了每日强度前 40 个精选板块（2,420 board-day），不是全市场板块；
2. 4,746 条可研究信号只覆盖有回补归属的股票；未回补板块的股票被排除，A 组也因此不是全市场趋势信号；
3. 2026-07~09 是一个特定市场阶段，绝对收益为负；组间比较仍公平，但不能外推到其他阶段；
4. 没有行业中性化；板块归属与行业暴露高度重叠；
5. 40/60 日样本日期太少，已明确标记不可判断。
