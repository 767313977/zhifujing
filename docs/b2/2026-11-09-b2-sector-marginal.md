# B2.3 板块条件边际贡献（同样本对照）

> 日期：2026-11-09
> 脚本：`scripts/validate_sector_resonance.py`（新增 `marginal_effects`）
> 数据：`b1_research.db`，60 个交易日、每日强度前 40 个精选板块
> 证据：`backend/data/b2_sector_marginal.json`（未提交）
> 结论：**B/C/D 的组间差异主要来自“哪些日期有信号”，不是板块条件本身；同样本同日对照下，板块条件没有可靠增量。**

---

## 1. 方法

B1.3 的 A~E 是**不同子集**，平均收益会受「哪些日期恰好有符合条件的票」影响。B2.3 在**共同候选集合、共同信号日期**上做同样本对照：

- 对每个信号日，分别取「满足板块条件」与「同一天不满足条件」的两组；
- 先算每日两组均值之差，再对日期等权平均，得到 `date_matched_diff`；
- `overall_diff` 是不分日期的混合均值差，仅作对照；
- 价格、持有期、费用、可成交性、市场/板块过滤完全一致。

---

## 3. 关键发现

1. **B/C 的“更差”主要是日期结构**：混合差 −6.59 / −13.55 / −16.59，但同日匹配后只剩 −0.65 / +0.52 / −0.10。
2. **D 的“更好”也是日期结构**：混合差 +1.03 / +3.68 / +7.10，但同日匹配后为 −0.73 / −0.87 / −0.53；**没有稳定增量**。
3. **E 的负向小而一致**：同日匹配 −1.06 / −0.76 / −1.21，说明按板块 RPS 排序不但没有帮助，反而略差。
4. 板块条件没有通过「共同候选、共同日期」的边际检验；把它作为硬性选股门槛会改变样本日期结构，而不是提供 alpha。

---

## 4. 结论

- 撤销「强板块 + 强个股」作为默认选股策略；
- 板块强度保留为**市场背景、轮动研究、风险解释变量**；
- 若后续要把板块指标用于排序，必须先做同样本、同样日期的增量检验，并给出样本覆盖变化；
- 不得用 B1.3 的组间均值差（含日期结构）冒充板块条件的边际贡献。
