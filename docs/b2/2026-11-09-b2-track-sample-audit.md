# B2.4 新旧 Track 逐样本差异审计

> 日期：2026-11-09
> 脚本：`scripts/compare_track_kernel.py`
> 数据：`b1_research.db`，20 个循环 × 50 只 = 1,000 条信号
> 证据：`backend/data/b2_track_sample_audit.json`（未提交）
> 结论：**统一时间轴后，逐样本收益一致，0 个未解释差异。**

---

## 1. 时间轴映射（本次修正的核心）

| 项 | 旧 `/patterns/track` | 新内核 `entry=close` |
| --- | --- | --- |
| 收益起点 | 信号日收盘 | 信号日收盘 |
| 第 1 个点 | 信号日**后第 1 个交易日**收盘 | horizon 1 = 信号日收盘（0 收益） |
| 第 n 个点 | 信号日后第 n 个交易日收盘 | horizon n+1 = 信号日后第 n 个交易日收盘 |

因此正确映射是：

> **旧 step n ↔ 新 horizon n+1**

B1 报告曾用「step n ↔ horizon n」比较，导致 step 1 出现 −44.8pp 的上涨占比差；那不是计算缺陷，而是差了一天。

---

## 2. 逐样本统计

| 差异类型 | 样本数 | 说明 |
| --- | ---: | --- |
| `consistent` | **13,179** | 同一股票、同一信号日、同一绝对退出日，收益差 ≤0.05pp |
| `both_missing` | 6,626 | 两侧都没有有效行情（数据末端/停牌/无行） |
| `old_missing` | 11 | 旧侧没有行，新侧有 |
| `new_not_executable` | 184 | 新内核判为开盘涨停不可买/退出跌停/停牌等 |
| `time_axis` | **0** | 绝对退出日不同 |
| `unexplained` | **0** | 无法解释的数值差异 |

**旧均值与新均值的小幅差异**来自样本集合不同：新内核排除了 184 个不可成交样本，旧侧仍把它们计入；这不是同一股票同一天的收益计算差异。

---

## 4. 结论

1. 统一时间轴后，**所有能对齐的样本收益完全一致**（差 0.00，容差 0.05pp）；
2. 没有 `time_axis`、没有 `unexplained`；
3. 差异只剩：
   - 旧侧没有行情/新侧有（11）；
   - 新内核判为不可成交（184）；
   - 两侧都没有有效行情（6,626）。
4. B1 报告里的 0.77pp 均值差，是「旧 step n 对新 horizon n」的 off-by-one 映射 + 样本集合差异造成的，**不是内核计算缺陷**；
5. 正式 track 路由仍未替换；若要切换，应先在产品层展示「不可成交/停牌/数据末端」状态，并统一基准时点。

---
