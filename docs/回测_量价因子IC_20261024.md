# 量价因子横截面 IC（2021-09 ~ 2026-10，5 年 / 约 4900 只）

> 日期：2026-10-24
> 脚本：`scripts/factor_ic.py`（新增）
> 数据：`backend/data/history.db`（1300 根 ≈ 1230 个交易日），零外部请求
> 口径：每日横截面 Spearman 相关；未来收益 = 之后 h 个交易日 `pct_chg` 复利

## 1. 怎么读这张表

```
IC_t   = Spearman( 因子_t 排名, 未来 h 日收益排名 )
均值IC  = 各交易日 IC 的平均（>0 表示因子越大、未来收益越高）
IR     = 均值IC / IC 标准差
t 值   = IR × √有效天数（|t| < 2 基本等于没有稳定信号）
多空差  = 每日「因子前 20% 的平均收益 − 后 20% 的平均收益」再取平均
```

**IC 只说明「排序有没有信息」，不等于能赚这么多**：多空差是 20% 对 20% 的组间差，
还没扣手续费、印花税、滑点和冲击成本。

## 3. 稳健性：换持有期与样本期，方向不变

| 因子 | 5 日 IC（5 年） | 10 日 IC（5 年） | 5 日 IC（近一年） |
|---|---:|---:|---:|
| `rev20` | +0.0622 | +0.0744 | +0.0457（t=4.1） |
| `illiq20` | +0.0576 | +0.0742 | +0.0495（t=4.8） |
| `rev5` | +0.0340 | +0.0398 | +0.0115（t=1.1，**不显著**） |
| `gap20` | +0.0207 | +0.0261 | +0.0252（t=5.0） |
| `amp20` | −0.0794 | −0.0884 | −0.0606（t=−3.6） |
| `maxret20` | −0.0758 | −0.0853 | −0.0680（t=−5.3） |
| `corr20` | −0.0570 | −0.0635 | −0.0473（t=−8.2） |

10 日持有期的多空差更大（`rev20` +1.07%、`illiq20` +1.23%），说明这类信号**衰减慢**，
不是隔夜抢帽子的东西。近一年方向与全样本一致，只有 `rev5` 变弱。

## 4. 结论

1. **A 股的横截面是「反向 + 低波动」**：20 日反转、低流动性、低振幅、小上影线、
   低单日最大涨幅 —— 全都在同一侧，且 t 值远超 2。这与 RPS（追强）在长历史里为负，
   是同一件事的两面。
2. **动量为负**（`mom60` −0.0585）：和 RPS 长历史的结论一致，别在 A 股做长周期追强。
3. **量价相关为负**（`corr20` −0.057，t=−20.5，是全表最「显著」的）：
   收盘与成交量同向变动越强，后面越弱 —— 典型的「放量拉升后接不住」。
4. **可用性**：这些因子适合做**排序 / 打分权重**，不适合单独当买卖信号 ——
   5 日多空差 0.3~0.65%，扣掉双边约 0.13% 后仍有空间，但换手会吃掉大半。
   要用的话应该做成「在候选池内按因子分位加权」，而不是全市场按因子选股。

## 5. 局限（决定这些数字不能直接当收益）

- **未扣费用**：佣金 + 印花税 + 滑点；因子若每周换仓，成本会吃掉 0.3~0.6pp；
- **没做行业/市值中性化**：`illiq20` 的 IC 有一部分其实是小市值效应；
- **没做分组单调性检验**：只看了前 20% 与后 20%，中间三组是否单调没验证；
- **退市股**：代码取自窗口内出现过的全部股票（不是最后一天还在的），但 `history.db`
  本身来自腾讯回补，早期退市股可能整段缺失；
- **未剔除 ST**：ST 股的涨跌停规则不同，会污染 `maxret20` / `amp20` 这类因子；
- IC 是「全市场截面」，实际组合只有几十只，组合层面的跟踪误差会远大于 IC 的 t 值给出的信心。

## 6. 复现

```bash
python scripts/factor_ic.py                    # 5 年、5 日持有期
python scripts/factor_ic.py --horizon 10       # 10 日
python scripts/factor_ic.py --bars 260         # 只跑近一年
python scripts/factor_ic.py --db main --bars 400   # 换主库
```
