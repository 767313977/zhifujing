## 1. G-1 趋势候选空结果歧义（P0-1）

### 1.1 改动

`research_screen.day_coverage()` 先按交易日统计三个数（都是 COUNT，不读全表）：

- `daily_rows`：当日 `stock_daily` 行数；
- `rps_rows`：当日 `rps_daily` 行数；
- `rps60_rows`：当日 `rps60` 非空行数；
- `rps_coverage = rps60_rows / daily_rows`。

五态语义（写进 `DATA_STATUS_TEXT`，接口原样返回）：

| `data_status` | 触发条件 | 含义 |
| --- | --- | --- |
| `no_bars` | `daily_rows = 0` | 底层行情缺失（未来日期 / RPS 孤儿日） |
| `no_rps` | 有日线、`rps_rows = 0` | 当日 RPS 未采集 |
| `no_rps60` | 有 RPS 行、`rps60_rows = 0` | 旧版本数据或窗口不足 |
| `partial_rps` | `rps_coverage < 0.9` | 横截面不完整，分位不可比 |
| `ok` | 以上都不满足 | 数据完整；此时空结果才是「无候选」 |

`_trend_rows()` **先判覆盖再取候选**：非 `ok` 直接返回空表 + 覆盖原因；`ok` 但候选为 0 时给出
`note="当日数据完整，但没有 RPS60 ≥ 60 的股票"`。

### 1.2 契约兼容

`rows / trade_date / strategy / candidates / with_boards / bars` 全部保留；只新增字段，
旧前端不读新字段也不会坏。

### 1.3 测试

## 2. G-2 低位启动的 RPS 缺失标记（P0-2）

### 2.1 改动

行级新增 `rps_status`，并按三种原因写 `missing[]`：

| 场景 | `rps_status` | `missing` |
| --- | --- | --- |
| 当日 `rps_daily` 一条都没有 | `day_missing` | `RPS20 缺失（当日 RPS 未采集）` |
| 当日有 RPS 行、但没有这只票 | `no_row` | `RPS20 缺失（当日无该股 RPS 记录）` |
| 有该股 RPS 行、`rps20` 为空 | `window` | `RPS20 缺失（20 日窗口覆盖不足：停牌或数据缺失）` |
| 有值 | `value` | `[]` |

接口级 `coverage` 同时给出 `rps_rows / rps60_rows / rps_coverage / data_status /
rps_missing_rows / excluded_short_bars`。

关键边界：

- **不把 NULL 改成 0**，也不因为 RPS 缺失剔除股票（低位启动不依赖 RPS）；
- `excluded_short_bars = candidates − built`：把「不足 250 根可用日线（新股/历史不足）」
  与「RPS 缺失」分开统计；
- 复权与形态算法（`build_bars`、`trend.TREND_LOOKBACK`）未改。

## 4. G-4 板块指标不足被静默剔除（P0-4）

### 4.1 计数口径（集合关系可验算）

```
boards_in_day            = 当日有板块日线的板块数
boards_with_history      = 其中窗口内 ≥20 个交易日（能算 20 日 RPS）的板块数
boards_with_rps20        = 当日有 rps20 的板块数（= matched）
excluded_short_history   = boards_in_day − boards_with_history
excluded_no_rps20        = boards_with_history − boards_with_rps20
returned                 = 实际返回条数（受 limit 影响）
truncated                = matched − returned
window_only_boards       = 窗口内出现过、但当日没有日线的板块（独立分母）
```

恒等式：`boards_in_day = boards_with_rps20 + excluded_no_rps20 + excluded_short_history`。

覆盖统计与「市场强弱」严格分开：筛选后样本变少只体现在 `matched/returned`，
不会被当成板块走强或走弱。

### 8.1 行为

| 入口 | 模式 | 行为 |

| 开发机 `python -m app.main` | `migrate`（`__main__` 显式设置） | 保留原来的自动补列/建表便利 |
| 运维命令 | `scripts/migrate_db.py --apply` | 显式迁移，可 `--backup`、`--status` 只读检查 |

- migrate 幂等（第二次 0 列 / 0 索引）；
- `PRAGMA query_only=1` 的连接上 `schema_report` 正常返回（只读安全）；
- 非法模式报错；源码级约束 `main.py` 不含 `init_db()` 调用。
