| 源码版本 | 178/178 的 blob 与 `fe2005f` 相同 |
| 前端产物 | 54/54 摘要相同，汇总摘要 `2f819e0b…` |
| 二进制可复现 | 连续两次打包 SHA256 **完全相同**（`85efc666…`） |

固定下来的规则（本次改造）：

1. 成员顺序按 **POSIX 字符串**排序（区分大小写），Windows/Linux 一致；
2. tar 成员 `mtime = 0`、`uid/gid = 0`、`uname/gname = root`；
3. gzip 头 `mtime = 0`、`filename` 留空；
4. 文件 0644、目录 0755。

**内容集合一致 ≠ 二进制摘要一致**：即使文件逐个相同，时间戳、成员顺序、权限、
gzip 元数据任一变化都会改变 tar 的 SHA256。本轮上述四项已固定，同机重打两次结果相同；
若换机器仍不同，需先确认 zlib 版本与 tar 实现，再判断是否属于未登记差异，
不能仅凭「文件数相同」宣称可复现。
