# 从板块强度落到个股：三种检验（2026-10-25）

## 0. 数据前提

`sector_member` 原先只有「当晚 22:00 预取 + 打开板块时现取」两条写入路径，2026-09-28
之前基本是空的。用 `scripts/backfill_sector_members.py` 回补后：

- 覆盖 **2026-07-24 ~ 2026-10-23（60 个交易日）**，每天 372~374 个板块、5800+ 只票；
- 写入 393.9 万行，0 个板块失败，耗时 108 分钟；
- 与 `sector_daily` 最近 60 个交易日 **100% 对齐**。

⚠️ 回补抓的是**当时**的成分（单板块 801001：2026-03-02 是 970 只、2026-10-23 是 1136 只），
不是拿今天的名单回填，所以不存在前视偏差。

## 1. 口径

- 板块强度 = `sector_rps.rps20_on`：板块指数 20 日复利涨幅的横截面分位（与页面同口径）；
- 个股 = 当日 `sector_member` 里属于该板块的票（精选板块口径 `kph_selected`），
  **剔除 ST 与北交所**（`patterns.is_st` / `limit_rules.is_bse`，与首板池、页面同一套）；
- 买入 = D+1 **开盘价**，卖出 = D+1 **收盘价**；D+1 开盘已在涨停板的剔除
  （`backtest_relay._tradable`，与首板/接力回测同一套）；
- 基准 = 当日全市场等权（同一套剔除）。

脚本：`scripts/backtest_sector_stock.py --mode all --days 60`
实测 **59 个信号日（2026-07-24 ~ 2026-10-22）**。

## 3. 结论

1. **「板块强 → 个股强」在这段时间不成立，方向是反的**：IC −0.046（t=−1.8），五分位
   收益单调递减；强势板块里追当日涨幅前 3 的票，超额 −0.17%，而弱势板块同样取法 +0.11%。
   剔除 ST / 北交所之后弱势档的超额从 +0.34% 降到 +0.11% —— 原先那部分主要来自
   ST 票（涨跌幅 10% 但波动更大），不是「板块弱」本身的信息。
2. **叠板块强度会削弱突破形态**：全市场「当日命中突破形态」超额 +0.18%，限定在强势
   板块里只剩 −0.30%。也就是说「强势板块 + 突破」是把有效信号（突破）与无效/反向信号
   （板块动量）相乘，反而变差。
3. 与 `docs/回测_RPS与趋势模板_20261024.md` 的结论一致：**RPS 类动量在本库覆盖的样本里
   没有正向选股能力**；有效的仍是 20 日反转、低波动、非流动性（
   `docs/回测_量价因子IC_20261024.md`），以及形态本身。
4. 2026-10-25 按要求上线为**研究视图**（选股池第四块 `/api/pools/sector-stock`）：
   强势 / 弱势两档、涨幅 / 因子分两种排序都能看，页面标题与说明里写明「历史负超额」
   并给出上面三个数字 —— 目的是让人看见「板块强 ≠ 个股强」，不做买入推荐。

## 4. 局限

- 59 个交易日、单一行情环境，IC 的 t=−1.8 未达显著；分组单调性只是方向证据。
- 精选板块之间有大量重叠（同一只票挂多个板块），个股层面已按「所属最强板块」去重，
  但板块层面的强度仍不是独立样本。
- 未扣费用；「弱势板块 + 当日涨幅前 3」的超额 +0.11% 在扣掉双边成本后基本抹平，
  不能当成可用策略。
- 想扩样本就再跑 `scripts/backfill_sector_members.py --days 120`（约 3.5 小时），
  然后 `--days 120` 重跑本脚本。
