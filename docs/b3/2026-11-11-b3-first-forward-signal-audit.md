## 4. D+1（2026-11-12）纸面跟踪依赖

规则（以 `research_backtest` 源码为准）：

- `_find_entry`：`for offset in range(1, max_entry_delay + 1)`，默认 5 →
  **最多 5 次入场尝试**，不存在第 6 次；
- `_find_exit`：`target = entry_pos + horizon - 1`，
  `for offset in range(0, max_exit_delay + 1)`，默认 10 →
  **目标退出日 + 最多 10 个交易日**（含 offset=0，共最多 11 个尝试位置）；
- 入场按 D+1 开盘价；退出按第 5 个交易日收盘（入场日计为第 1 日）。

- 最大退出依赖窗口：按实际入场日动态计算，全局最晚 **2026-12-08**；

### 状态与可执行性口径

| 状态 | 含义 | 是否计入收益 |
| --- | --- | --- |
| `pending` | 数据窗口尚未成熟（尝试窗口越过库内最新日） | 否；不填零 |
| `suspended` | 5 次入场尝试内始终无行情 | 否 |
| `unbuyable` | 有行情，但开盘价已在涨停板（`_entry_limit_up`）；**直接判不可买，不顺延** | 否 |
| `entry_limit_up` | 标记（flag），不是独立 Sample 状态 | 随所属样本 |
| `no_quote` | 信号日无行、代码/日期不在矩阵，或入场价无效 | 否 |
| `no_exit` | 目标退出日 + 10 个交易日内都没有可用行情 | 否 |
| `exit_limit_down` | 有理论退出价，但收盘/最低价触及跌停；可能卖不出 | **理论观察值；`HorizonStat` 不计入执行统计** |
| `ok` | 按规则正常完成（含延迟入场/退出但未触发涨跌停限制） | 是（execution） |

要点：

1. 涨停不可买 → `unbuyable`，不会自动顺延到下一日；无行情才进入 `_find_entry` 顺延逻辑。
2. 无行情顺延与涨停不可买是两条不同路径；后者一旦命中即终止。
3. 退出顺延只由“无行情”驱动；跌停导致的 `exit_limit_down` 不改退出日，只标注风险。
4. `exit_limit_down` 的 `gross` 是理论价格观察值；`HorizonStat.mean` 只用 `ok`，
   前瞻工具展示“已入场且有退出价”时会把延迟退出样本一起展示，但必须标注不是真实成交。
5. 所有结果都是**信号层价格观察 + 可执行性假设**，不是组合净值或真实成交。
6. `pending` 不进入 `execution_samples`，不会把未成熟样本计入收益。

[2026-11-11-b3-forward-calendar-extension-plan.md](2026-11-11-b3-forward-calendar-extension-plan.md)：
