## 1. 上表的三处错误（已修正）

| 原表述 | 实际 |
| --- | --- |
| `entry_blocked = 0` | **100**（状态键是 `unbuyable`，不是 `entry_limit_up`） |
| `exit_completed = 23,868` | 那是 `ok`；另有 **151** 条 `exit_limit_down` 已入场且**有真实退出价** |
| C0 «六年全正» | 含延迟退出后 **2024 ≈ 0.00**，不是全正 |

`observed 24,220` 的互斥分解（C0）：

```
ok                 23,868   ← 正常退出
exit_limit_down       151   ← 入场成功、退出延迟到首个可卖日（有真实价格）
pending               100   ← 已入场、期末未到退出日（未成熟，不是失败）
unbuyable             100   ← 入场日开盘涨停，买不到
suspended               1   ← 入场日停牌
no_exit                 0   ← 入场后延迟上限内仍无有效价格
合计               24,220
```

不变式：`ok + exit_limit_down + pending + unbuyable + suspended + no_exit = 全部信号`。
**入场成功率 = (23,868+151+100)/24,220 = 99.6%**；真正卖不掉（`no_exit`）= **0**。

九组策略的状态分布同时输出（A 有 5 条 `no_exit`、C1 2 条、C2 3 条），用于检查「是否靠排除困难退出获得优势」。

## 3. 三种超额（必须分开读）

以 C0、30bps 为例：

| 口径 | 值 | 含义 |
| --- | ---: | --- |
| A. 毛超额 `gross − bench` | **+0.33pp** | 双方都不扣费 |
| B. 双方同成本净超额 | **+0.329pp** | 策略与基准各自扣一次往返成本 |
| C. 策略净 − 基准毛 | **+0.03pp** | 基准零成本时的「净优势」 |

C 只有 +0.03pp，说明**策略自身的成本几乎吃掉了全部超额**；B 仍为 +0.33 的前提是
「基准同样每日换仓」—— `Benchmark` 正是每天等权重建，这个前提成立。

结论：对外应引用 **B**，并同时披露 C。不得只报 A 就宣称「扣费后仍有超额」。

## 6. 判定

**维持 `FORWARD_PAPER_TRACKING_CANDIDATE`，但下修三处**：

1. 收益从「净 +0.35%」修正为 **+0.28%**（含延迟退出）。
2. 年度从「六年全正」修正为 **六年非负，2024 约为 0**。
3. 净优势按 B 口径为 +0.33pp、按 C 口径仅 +0.03pp，**成本吃掉几乎全部超额**。

支撑理由未变：C0−C1、C0−C2 的配对差显著（t=3.84/3.31，CI 不含 0），且风险指标优于 A。

不满足的条件：50bps 净收益仅 **+0.08%**；100bps 转负。因此**不进入资金层**。
