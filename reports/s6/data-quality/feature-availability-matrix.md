# S6-C3/C4 功能可用矩阵（灰度范围）

| 功能 | 质量状态 | 灰度可用性 | 限制 / 说明 |
| --- | --- | --- | --- |
| 登录 / 登出 / 注册 | VERIFIED | 可用 | 需要独立可写用户库（当前与主库同库 → G7 阻塞项） |
| 质量控制台 | 混合（VERIFIED / PARTIAL / NOT_COLLECTED / SOURCE_ERROR） | **只读可用** | 逐项显示状态、`as_of`、来源、分母；不补采 |
| 盘后研究工作台 | PARTIAL / 依赖感知 | **只读可用** | 缺依赖时显示「不可验证/未采集」，不写 0 |
| 涨停晋级漏斗 | 依赖涨停池 | **受限可用** | 涨停池 `NOT_COLLECTED` 的日期必须显示状态；不进入策略排序 |
| 竞价异动 | `REAL_AUCTION_DATA_NOT_VERIFIED` | **受限可用/建议禁用** | 页面必须标注「真实竞价数据未完成验收」；无 0926 不生成竞价涨幅；无 0931 不生成开盘承接变化；`PENDING` 不写 0；指标不得进入 C0/Top20/交易信号 |
| 情绪次日分析 | PARTIAL / NOT_COMPARABLE | **只读可用** | 7 条 `NOT_COMPARABLE` 保留；缺依赖时 `limit_up_again=None` |
| 板块共振 | 依赖板块成员覆盖 | **受限可用** | 覆盖不足返回 `PARTIAL/UNVERIFIABLE`，不伪造空交集 |
| 题材交集 | `THEME_REAL_DATA_ACCEPTANCE_PENDING` | **受限研究工具** | 保留 `taxonomy`、`as_of`、来源与覆盖数；不得作为已验证历史策略信号；不得自动加入 C0 |
| 个股研究侧栏 | PARTIAL（新闻/公告/研报按来源） | **只读可用** | 每个来源单独显示状态；外呼关闭时显示本地已有数据 |
| `as_of` 刷新 / 多窗口同步 | 前端行为 | 可用 | 依赖浏览器验收（见 `staging/browser/`） |
| C0 / Top20 / 交易信号 | 保持既有冻结逻辑 | **不新增** | 本轮不接入任何新指标；冻结信号与 C0 五脚本未修改 |
| 自动交易 / 下单 | 不存在此功能 | **禁用** | 代码库无下单链路 |
| 后台定时采集 | scheduler | **禁用** | `SCHEDULER_ENABLED=false` |
| 外部实时取数 | 外部来源 | **禁用** | `EXTERNAL_DATA_FETCH_ENABLED=false` + 允许名单 |
| 飞书推送（webhook） | 推送 | **禁用** | 灰度不配置，避免外呼 |
| 飞书推送（lark-cli 子进程） | 推送 | **禁用** | 应用层无法约束子进程出口 |

## 1. 明确不允许进入 C0 / 策略排序的数据

- 竞价（真实数据未验收）；
- 题材真实成员覆盖未通过的指标；
- 质量状态为 `NOT_COLLECTED` / `UNVERIFIABLE` / `SOURCE_ERROR` / `PARTIAL` 的结论；
- 7 条 `NOT_COMPARABLE` 对应的情绪次日指标。

## 2. 页面必须显示的内容

1. `as_of` 与观察日期；
2. 最新资料截至日；
3. 来源（iFinD / 东财 / 同花顺 / 本地库等）；
4. 分母与样本范围；
5. 未完成/缺失数量（`None` 不是 0）。
