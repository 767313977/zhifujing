# M6.2 Batch 6：未来研究预注册协议

- 状态：**仅设计，不训练、不调参、不跑新模型。**
- 适用对象：M6.2 之后任何新的趋势研究项目（不限于 A/B）。
- 冻结前提：Model A/B 及 A+B 仍保持 M6.1「未通过」状态；A2/B2 权重、阈值、过滤条件为历史版本，不得复活。
- 核心原则：**所有准入标准在查看新测试集之前固定**，并写入 Git（本文件 + 配置文件的 SHA）。

---

## 1. 研究假设与经济机制

### 1.1 假设

| 编号 | 假设 | 可反驳条件 |
| --- | --- | --- |
| H1 | 中期均线走平转上、波动收敛后放量突破的股票，在未来 20 个交易日具有正的相对基准超额 | 日期聚类 Bootstrap 下界 ≤0 |
| H2 | 已形成上升趋势、缩量回踩均线后重新放量的股票，未来 20 日相对超额为正 | 同上 |
| H3 | 上述效应不能被「市场环境 + 市值 + 行业」完全解释 | 分层后超额不显著或符号反转 |

### 1.2 经济机制（必须写清，不接受纯数据挖掘）

- 趋势启动：信息扩散与资金再配置存在摩擦，突破后的初始动量在数周内延续；
- 趋势延续：机构建仓后的回撤吸筹形成支撑，缩量回踩代表抛压衰减；
- 机制失效场景：流动性枯竭、监管冲击、极端风险偏好反转。

## 2. 数据与 PIT 要求（前置条件）

| 字段 | 要求 | 当前状态 |
| --- | --- | --- |
| 个股日线 | 含 `available_at` / `ingested_at` / 复权因子 | 缺失 |
| 指数日线 | 与个股同日、无缺口 | 滞后 5 日 |
| 板块成分 | 每日快照或带 in/out 日期 | 仅 60 天 |
| breadth | 按 `06-breadth-calculation-spec.md` 可复现 | 空表 |
| RPS | 单一版本、带 `version_id` | 混版本、无版本 |
| ST 历史 | 公告驱动 | 不可证明 |
| 退市 | 名单 + 最后交易日 | 0 只 |
| 行业/市值 | 历史序列 | 仅当前快照 |
| 交易价格 | **前复权**（或明确用不复权 + 公司行为表） | 未复权 |

未满足的字段：相关特征必须返回 `UNKNOWN`，不得进入信号；若研究方案不依赖该字段，需在预注册中显式声明并说明理由。

## 3. 研究设计（固定项）

| 项 | 规定 |
| --- | --- |
| 股票池 | 全 A（含退市），剔除：上市 <120 个交易日、当日无成交、停牌、ST（若 ST 历史可用） |
| 信号时点 | T 日收盘后（15:00 之后），只使用 `available_at ≤ T 收盘` 的数据 |
| 成交时点 | 最早 T+1 开盘；涨停不可买、跌停不可卖、停牌顺延 |
| 持有期 | 主口径 20 个交易日；辅助 5/10/40/60；不得只报告最优期限 |
| 基准 | 同入场/退出日的全市场等权收益（可成交口径）；指数基准仅作辅助，且不得使用滞后数据 |
| 成本 | 佣金 3bps（双边）、印花税 10bps（卖出）、滑点 10bps（双边）、最低佣金 5 元；与 M6.1 一致，不得下调 |
| 仓位 | 单股 ≤10%、最多 20 只、现金不足按分数排序分配；组合层另设总暴露上限 |
| 因子方向 | 必须**事先声明方向**；RPS、板块强度默认方向为「待检验」，不得默认正向 |
| 因子消融 | 每个因子必须有：单独、去掉、分组（五分位）、交互、分窗口稳定性 |

## 4. 时间切分与防泄漏

| 项 | 规定 |
| --- | --- |
| 切分 | 按时间 60% 训练 / 20% 验证 / 20% 测试；切分日期在预注册中写死 |
| Purge | 训练与验证、验证与测试之间，剔除标签窗口重叠的样本（20 日标签 → 至少剔除 20 个交易日） |
| Embargo | 每段评估前再留 5 个交易日缓冲（比 M6.1 的 20 日更严或相同，不得放宽） |
| 逐块再训练 | 若声称 Walk-forward，必须**逐块重训**；否则只能称「分块评估」 |
| 测试集 | 冻结前不得用于任何排序、选型、阈值选择、报告筛选；冻结物 = 配置 + 代码 SHA + 数据 SHA |
| 多重检验 | 预注册变体数 k；Bonferroni α=0.05/k，或 Holm；报告未校正与校正结果 |

## 5. 统计口径（固定）

| 项 | 规定 |
| --- | --- |
| 重采样单位 | 交易日（同日多只股票为一个簇） |
| Bootstrap | percentile，≥2,000 次，固定 seed 并记录；同时报告簇数量 |
| 最小独立样本 | **≥200 个有效交易日**（不是 200 条信号） |
| CI | 95%，下界 >0 才算通过 |
| 尾部依赖 | 前 5% 盈利贡献 ≤50%；剔除前 5% 后均值必须 >0；总收益为负时不得报告「尾部贡献率」 |
| 市场环境 | 至少 2 种环境各自 ≥30 个交易日，且每种环境超额不为负 |
| 行业分层 | 至少 5 个行业有 ≥30 个独立日；不得由单一行业贡献 >50% 收益 |
| 市值分层 | 至少 2 个市值组为正，且不得只在小市值组有效 |
| 稳定性 | 至少 3 个独立时间块方向一致；任一块为负需解释 |

## 6. 交易级回测门槛

| 项 | 规定 |
| --- | --- |
| 价格 | 前复权成交价 + 原始价涨跌停判定（或等价方案），必须证明一致 |
| 成交 | T+1 开盘、涨跌停/停牌、整手、现金约束、单股/总数上限 |
| 成本 | 与第 3 节一致，双边计入 |
| 账本 | 逐笔交易账本 + 逐日资产账本，恒等式误差 <0.01 元 |
| 期末持仓 | 必须按最后收盘价强制平仓或单独报告「未平仓浮盈」，不得混入已实现收益 |
| 停牌/退市 | 明确处置规则；不得无限期按最后价计值 |
| 报告 | 固定持有、ATR 止损、结构退出、组合风控、组合+个股退出，五组并列 |

## 7. 准入判定（全部满足才算通过）

1. 测试集 20 日超额均值 >0；
2. 日期聚类 Bootstrap 95% CI 下界 >0，且有效交易日 ≥200；
3. 至少 3 个独立时间块方向一致；
4. 剔除前 5% 后均值 >0；
5. 至少 2 种市场环境不为负；
6. 行业与市值分层不出现「仅单一组有效」；
7. 交易级模拟账本恒等、成本计入、期末持仓处理正确；
8. 多重检验校正后仍显著（或明确报告未通过校正）。

任一条不满足 → **未通过**，不得用「接近」「趋势向好」替代。

## 8. 失败与停止规则

| 触发 | 动作 |
| --- | --- |
| 数据 PIT 无法证明 | 停止研究，回到数据治理 |
| 发现未来数据泄漏 | 立即作废该轮全部结果，保留证据，重做 |
| 独立交易日 <200 | 结论标记 `INSUFFICIENT_SAMPLE`，不得宣称有效 |
| 验证集为负 | 冻结、停止调参；测试集最多作描述性诊断 |
| 调整参数后测试集变好 | 视为过拟合，测试集作废 |
| 两次独立复现结果不一致 | 停止发布结论，先修确定性 |
| 组合仅在降低暴露后改善回撤 | 只能称「降风险」，不得称 alpha |
