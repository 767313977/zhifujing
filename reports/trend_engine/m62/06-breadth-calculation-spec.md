# M6.2 Batch 3：市场宽度 breadth 计算规范

- 目的：把 `breadth_daily` 从「空表」变成**可复现、可核对**的定义，而不是直接回填数字。
- 数据源：`stock_daily`（不复权收盘、涨跌幅、成交额）+ `trade_calendar`（日期轴）。
- 双实现核对：SQL 窗口函数 vs 纯 Python 逐股滚动，3 个抽样日**逐项一致**（`sample_day_reconciliation.csv`）。

---

## 1. 定义

### 1.1 交易样本（universe）

某交易日 `d` 的**有效样本**满足：

```
close IS NOT NULL AND amount > 0 AND pct_chg IS NOT NULL
```

| 情况 | 处理 |
| --- | --- |
| 当日无记录（停牌/退市） | 不计入任何分母 |
| `amount <= 0` 或为空 | 视为无成交，剔除 |
| `pct_chg` 为空 | 无法判定涨跌，剔除 |
| ST / *ST | **无法可靠识别**（无历史 ST 表）→ 不剔除，但字段级标记 `ST_STATUS=UNKNOWN` |
| 上市不足窗口（如不足 20 个交易日） | 只从**对应指标**的分母中剔除，不影响涨跌家数 |

### 1.2 涨跌平

| 指标 | 定义 |
| --- | --- |
| `up_count` | `pct_chg > 0` |
| `down_count` | `pct_chg < 0` |
| `flat_count` | `pct_chg == 0`（浮点比较用 `abs(x) < 1e-9`） |
| `universe_count` | 三者之和，等于有效样本数 |

### 1.3 均线

```
MA20(d) = mean(close, 最近 20 个有行情的交易日，含当日)
```

- **必须**连续 20 个该股交易日（允许中间停牌，按该股实际行数计，不用自然日）；
- 不足 20 行 → `above_ma20` 不计入，且分母也不含该股；
- `above_ma20 = close > MA20`（严格大于）。

`MA60` 同理，需要 60 行。

### 1.4 新高 / 新低

```
high20(d) = close(d) >= max(close, 最近 20 个交易日含当日)
```

等价于「今日收盘不低于此前 19 日的最高收盘」，即当日创 20 日新高（含当日）。
`low20` 用 `<= min(...)`；`high60` / `low60` 用 60 日窗口。

- 窗口按**该股实际交易日**计数，不按自然日；
- 不足窗口 → 不计入对应分母。

### 1.5 涨停 / 跌停（近似）

`stock_daily` 没有板块与 ST 标识，只能近似：

| 代码前缀 | 阈值 |
| --- | --- |
| 300 / 301 / 688 | 19.8% |
| 4 / 8 / 920 | 29.8% |
| 其他 | 9.8% |

- 该口径**忽略 ST（5%）与新股特殊规则**，只作近似；
- 权威口径应与 `limit_pool`（`pool_type=up/down`）交叉核对，二者不一致时以 `limit_pool` 为准并标记 `APPROX`。

### 1.6 缺失与禁止

- 任何指标缺失时写 `NULL` + 对应分母，**禁止填 0**；
- 禁止用前一日或最后一日向后填充；
- 禁止用「全市场所有代码」作分母而不说明有效样本；
- 同一天多只股票不得重复计入（`stock_daily` 已无 `(code, trade_date)` 重复）。

## 2. 双实现核对结果

抽样日：2025-12-31、2026-06-30、2026-09-24。

| 指标 | 2025-12-31 | 2026-06-30 | 2026-09-24 |
| --- | ---: | ---: | ---: |
| 有效样本 | 5,055 | 5,096 | 5,282 |
| 上涨 | 2,291 | 2,862 | 1,071 |
| 下跌 | 2,566 | 2,156 | 4,092 |
| 平盘 | 198 | 78 | 119 |
| MA20 上方 / 分母 | 2,689 / 5,040 | 1,421 / 5,087 | 2,111 / 5,264 |
| MA60 上方 / 分母 | 2,025 / 4,944 | 1,137 / 5,019 | 2,706 / 5,052 |
| 20 日新高 / 新低 | 564 / 467 | 454 / 1,255 | 267 / 969 |
| 60 日新高 / 新低 | 250 / 260 | 279 / 1,156 | 140 / 260 |
| 涨停（近似） | 57 | 143 | 54 |
| 跌停（近似） | 8 | 10 | 18 |
| SQL vs Python | **完全一致** | **完全一致** | **完全一致** |

涨停交叉核对（`limit_pool`）：

| 交易日 | 近似涨停 | `limit_pool.up` | 近似跌停 | `limit_pool.down` | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| 2025-12-31 | 57 | 59 | 8 | 6 | 差 2 只，`APPROX` |
| 2026-06-30 | 143 | 142 | 10 | 6 | 差 1~4 只，`APPROX` |
| 2026-09-24 | 54 | 52 | 18 | 13 | 差 2~5 只，`APPROX` |

差异来源：ST 5% 限制、新股上市首日规则、`limit_pool` 只收录特定类型的封板。**近似值不得当作权威涨停家数**。

## 3. 建议的 `breadth_daily` 存储结构

现有列：`trade_date, above_ma20, above_ma60, above_ma250, high60, low60, high250, low250, universe_count`。

建议扩展（新增表或加列，需授权）：

| 列 | 说明 |
| --- | --- |
| `up_count`, `down_count`, `flat_count` | 涨跌平 |
| `universe_count` | 有效样本 |
| `above_ma20`, `ma20_denominator` | 分母必须同时存 |
| `above_ma60`, `ma60_denominator` | 同上 |
| `high20_count`, `high60_count`, `low20_count`, `low60_count` | 与当前 `high60/low60` 命名统一 |
| `high20_denominator`, `high60_denominator` | 同上 |
| `limit_up_approx`, `limit_down_approx` | 近似值 |
| `limit_up_pool`, `limit_down_pool` | 来自 `limit_pool` 的权威值 |
| `quality_status` | `OK` / `APPROX` / `PARTIAL` |
| `source_version` | 计算脚本版本 |

比例字段（如 `breadth_ma20 = above_ma20 / ma20_denominator`）由下游计算，不落库，避免分母丢失。

## 4. 已知限制

| 限制 | 影响 | 处理 |
| --- | --- | --- |
| 收盘价不复权 | 除权日涨跌幅可能异常 | 涨跌平用 `pct_chg`（供应商已处理），均线/新高用不复权价 → 除权日附近可能误判 |
| 无 ST 历史 | 无法剔除 ST | 标记 `ST_STATUS=UNKNOWN`，不剔除 |
| 无停牌表 | 停牌只能由「无记录」推断 | 视为无样本，不计入分母 |
| 涨停近似 | 与真实封板数有 1~5 只差异 | 同时存近似值与 `limit_pool` 权威值 |
| 无 250 日早期数据 | 2024-09 起只有 506 天 | `high250` 只在足够历史时计算 |
