### 1.2 契约规则

1. **区间内不得断档**：上表已满足；补采后必须重新验证。
2. **不得用最后一日向后填充**：2026-09-25 ~ 10-09 的指数数据必须为「缺失」，不得复制 09-24 的值。
3. **基准选择**：
   - 默认基准是 `research_backtest.Benchmark(mode="market")`：**同入场/退出日的全市场等权收益**（剔除入场涨停、退出跌停，但不剔除 ST/次新）；
   - 指数基准 `mode="index:<code>"` 可选，但因指数滞后 5 个交易日，**最近 5 个交易日不得使用指数基准**，否则应返回 `UNKNOWN`；
   - 不得混用「全市场等权」与「指数」两套基准做同一组对比。
4. `up_count` / `down_count` / `limit_up_count` 来自数据商，口径未记录；**只能作参考**，不得替代 breadth 自算值（见 `06-breadth-calculation-spec.md`）。

## 2. 板块数据

### 2.1 现状盘点

| 项 | 结果 |
| --- | --- |
| 分类体系 | `kph_industry`（104 个板块）、`kph_selected`（279 个板块） |
| 日线区间 | 2025-09-08 ~ 2026-09-24（255 天） |
| 每日板块数 | 363 ~ 377（**随时间变化**） |
| 重复 `(sector_code, trade_date)` | 0 |
| 成分表覆盖 | **仅 60 个交易日**（2026-07-03 ~ 2026-09-24），每日 58,617 ~ 64,073 行 |
| 个股末日滞后 | 5 个交易日 |

每日板块数从 365（2025-09-08）到 363（2026-09-24），峰值为 377，说明**板块池本身在变动**；不能用当前板块列表回看历史。

### 2.2 板块收益一致性（成分等权 vs 板块日线）

对 3 个有成分快照的交易日，把当日成分股 `pct_chg` 等权平均，与 `sector_daily.pct_chg` 对比：

| 交易日 | 可对比板块数 | 差异 ≤0.5pp | 差异 ≤1pp | 最大绝对差 | 中位绝对差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2026-07-15 | 269 | 269 | 269 | 0.151 | 0.000 |
| 2026-08-14 | 272 | 272 | 272 | 0.022 | 0.000 |
| 2026-09-24 | 260 | 256 | 257 | **12.378** | 0.000 |

- 两个早期样本几乎完全一致，说明板块日线与成分等权口径基本同源；
- 2026-09-24 有 3~4 个板块偏差超过 0.5pp，最大 12.4pp → 可能是成分调整日或个别成分缺价，**该日板块收益需标记 `SUSPECT`**。

### 2.3 契约规则

1. 板块收益必须使用**当日成分快照**；当日无快照 → `UNKNOWN`，禁止用最近快照或当前成分回看。
2. 覆盖率闸门：当 `有效成分数 / 快照成分数 < 0.8` 时，该板块当日收益置 `UNKNOWN`。
3. 分类体系必须带 `taxonomy` + 版本；`kph_industry` 与 `kph_selected` 不得混合排名。
4. 板块日线与成分等权差异 >0.5pp 的日期标记 `SUSPECT`，该日期板块特征不参与打分。
5. 板块权重仍默认为 0 分；未通过未来验证前不得启用。

## 4. 本批次结论

1. 指数与板块在**各自区间内无断档、无重复**，但相对个股滞后 5 个交易日，最近 5 日必须 `UNKNOWN`；
2. 板块成分只有 60 天，任何跨越 2026-07-03 之前的板块特征都不可 PIT，必须降级；
3. 板块日线与成分等权在 2/3 抽样日完全一致，1 个抽样日存在 12.4pp 异常，需要标记而非修正；
4. 未通过本契约前，市场环境与板块特征不得进入选股条件。
