## F4/F5 修复

- 板块 RPS20 统一走 `rps.mid_rank`（并列同分），与 `sector_rps.rps20_on` 同值；
- 板块区间收益要求「至少 window 行」+「有效值 ≥90%」，否则 `None`，
  不进入横截面，也不给 0 分。

## 板块指标

- 广度（上涨比例 / 强势股数 / 集中度）只在 `sector_member` manifest 完整且
  与来源 Count 一致时可信；否则 `None` + `missing`；
- 持续性 = RPS20 ≥ 80 的连续天数（含当日）；
- 排名变化 = 当日排名 − 5 日前排名（正数表示上升）；
- 默认板块权重 **0 分**，可配置 0～5，**不做硬过滤**。

## 市场环境

- 数据源：`index_daily`（必需）+ `breadth_daily` + `market_sentiment` + `fear_greed_daily`；
- 至少 2 个来源可用才给结论，否则 `UNKNOWN`；
- 每个来源返回实际日期；来源日期不等于目标日 → `confidence=low` 并写明原因；
- 极端风险优先：跌停家数 ≥60 / 站上 MA20 <15% / 涨跌停强度 ≤−60 / 波动率 ≥35；
- 广度否决：指数在 MA20 上方但站上 MA20 个股 <30% → 不得判 BULL；
- `model_weight_factor`：BULL 1.0 / SIDEWAYS 0.95 / BEAR 0.85 / EXTREME 0.0 / UNKNOWN 0.9
  （只作为排序系数暴露，不改模型原始分）。
