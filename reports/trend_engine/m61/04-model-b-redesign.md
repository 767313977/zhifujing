# Model B 重设计（M6.1）

## 1. 归因证据（b1，240 天，20 日超额）

| 证据 | 数值 | 含义 |
| --- | ---: | --- |
| RPS20 Rank IC | -0.098 | 高位 RPS 不再加分（B 的 RPS 权重默认 3 分，影响有限） |
| sector_score IC | **-0.383** | 板块分位越高越差；最差 25% 的板块分 93.0，最好 25% 只有 80.7 |
| trend_days > 60 | -4.87 | 趋势过老、过度拥挤 |
| trend_days 21-60 | -0.51 | 主流区间也没有正超额 |
| pullback_atr | 1.75（差）vs 1.99（好） | 回撤太浅反而不好；需要「像样的回撤」 |
| ret60 | 49.8（差）vs 40.2（好） | 过去 60 日涨太多是风险 |
| distance_ma20 | 7.6（差）vs 6.8（好） | 偏离均线越大越差 |
| SIDEWAYS | -2.02 | 震荡市里延续信号最差 |
| 60 日超额 | +1.00，但前 5% 贡献 1.51、剔除后 -1.93 | 长持有有均值，但依赖尾部 |

**结论**：Model B 的问题是「买在趋势后段 + 板块过热 + 回撤太浅」，
本质是拥挤度与均值回归，不是趋势识别失败。

## 2. 重设计原则（预注册）

1. **RPS 权重 0**：只展示，不做正向加分；
2. **板块权重保持 0**：证据明确为负，且 B1 已给出负 IC；
3. **限制趋势年龄**：`trend_days ≤ 60`；
4. **限制偏离**：`distance_ma20 ≤ 8%`、`ret60 ≤ 60%`；
5. **要求有效回撤**：`pullback_atr ≥ 1.2`（不能是几乎没回调的加速段）；
6. **环境门控**：SIDEWAYS 不生成信号（证据最差）。

## 3. 预注册变体

| 变体 | 权重（结构/回调/量价） | 过滤 |
| --- | --- | --- |
| B0 | 40/30/30，RPS 3 | 当前生产口径（对照） |
| B1 | 50/30/20，RPS 0 | trend_days ≤60、distance_ma20 ≤8、pullback_atr ≥1.2 |
| B2 | 同 B1 | B1 + pullback_shrink ≤0.8（缩量回踩） |
| B3 | 同 B1 | B1 + regime ≠ SIDEWAYS |

每日最多 20 只，T+1 开盘，15 bps。

## 4. 接受标准

与 Model A 相同：训练选择 → 验证为正 → 冻结 → 测试 20 日超额 >0 且 CI 下界 >0；
否则未通过。

## 5. 已知偏差

- 归因使用全样本 → 测试集非完全纯净；`history.db` 作为独立复现集；
- 缓存只含原模型合格样本，无法恢复被原模型硬排除的样本；
- 行业/市值是当前快照，不能作为选股条件（只能作为事后分层）。
