# Model A 重设计（M6.1）

基于 `02-model-failure-attribution.md` 的证据，不凭经验调参。

## 1. 归因证据（b1，240 天，20 日超额）

| 证据 | 数值 | 含义 |
| --- | ---: | --- |
| RPS20 Rank IC | **-0.166** | RPS 越高，20 日超额越差（D1 +0.81 vs D10 -4.81） |
| RPS60 Rank IC | -0.086 | 同向 |
| distance_ma20 IC | -0.106 | 越偏离 MA20 越差 |
| amount_ratio20 IC | -0.081 | 突破日放得越大越差 |
| trend_days IC | +0.072 | 趋势持续越久略好（21-60 日组 +3.37） |
| 0-5 日趋势组 | -1.04 超额 | 刚站上均线的样本最差 |
| BEAR 环境 | -5.57 超额 | 弱市里突破信号系统性失败 |
| 前 5% 贡献 | 总收益 ≤0 时不可计算；剔除前 5% 后 -2.59 | 收益依赖极少数样本 |
| MFE/MAE | 1.23 | 有浮盈但守不住 |

**结论**：当前 Model A 的主要问题是「追强 + 追量 + 追 RPS」，
在弱市与刚启动阶段被均值回归打败；RPS 作为正向权重是负贡献。

## 2. 重设计原则（预注册，先于实验）

1. **RPS 不再作为正向权重**：设为 0，只保留为展示字段；
2. **抑制追高**：`distance_ma20 ≤ 10%`、`ret20 ≤ 30%`、`amount_ratio20 ≤ 5`；
3. **只做已形成的启动**：`trend_days ≥ 6`；`trend_days > 60` 不再视为启动；
4. **环境门控**：BEAR 不生成信号（评估时按 regime 过滤）；
5. **不增加新数据依赖**：不引入行业/市值（当前快照非 PIT）。

## 3. 预注册变体（只在训练/验证集选择，测试集只评一次）

| 变体 | 权重（结构/突破/量价） | 过滤 |
| --- | --- | --- |
| A0 | 40/30/30，RPS 3 | 当前生产口径（对照） |
| A1 | 50/30/20，RPS 0 | distance_ma20 ≤10、ret20 ≤30、amount_ratio20 ≤5、6 ≤ trend_days ≤60 |
| A2 | 同 A1 | A1 + regime ∈ {BULL, SIDEWAYS} |
| A3 | 同 A1 | A1 + convergence ≤6、platform_width ≤12、close_position ≥0.7 |

所有变体每日最多 20 只，T+1 开盘成交，15 bps。

## 4. 接受标准（与总计划一致）

- 训练集选出的变体必须在验证集 20 日超额 > 0；
- 冻结后测试集 20 日超额 > 0 且 bootstrap 95% CI 下界 > 0；
- 有效独立交易日 ≥ 200；至少 3 个非重叠窗口不为负；
- 不满足 → Model A 未通过，不得进入 M7。

## 5. 已知偏差

- 归因使用了全样本，变体设计受此影响；因此把 `history.db` 作为**独立复现集**，
  并明确 b1 测试集不是「完全未见过」的样本；
- 缓存只包含原始模型的合格记录，变体无法恢复被原模型硬排除的样本（保守限制）。
