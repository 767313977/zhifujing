## 2. 复权因子核验

除权日前后（600519，2026-06-26）：

| 项 | 观测 |
| --- | --- |
| 复权因子 | 8.6760 → **8.8814**（除权日跳变） |
| raw 收盘 | 1212.10 → 1168.63（-3.59%） |
| 复权收盘（返回） | 10514.30 → 10377.11（-1.30%） |
| `raw × factor` | 10516.0 → 10377.1 |
| 相对误差 | 最大 **1.89bp**（≈0.019%），来自收盘价精度 |

结论：

1. `adjusted_close = raw_close × cumulative_factor` 在样本内成立（1.9bp 内）；
2. 因子在除权日上升，符合**累计后复权因子**特征；
3. **但**：前复权与后复权都返回在同名「收盘价」列，没有方向字段；没有官方字段文档对照。按任务书「字段定义不清 → 停止」，**不得据此构造可用 adjusted 序列**。

## 4. G9 判定

| 子项 | 结果 |
| --- | --- |
| 因子字段存在 | 是 |
| 公式与官方定义一致 | **否**（无官方定义、列名歧义） |
| ≥3 个行为样本通过 | **否**（1 个可验证，其余缺金额） |
| raw / adjusted 分离 | 部分（可推断，但字段不可区分） |
| 现金流与股份变动分开记录 | **否**（无金额） |
| 公告时间 | **缺失** → PIT 不能 PASS |
| **G9 总判定** | **FAIL** |

未构造任何 adjusted series、未写 `price_factor` 数据（staging 表 0 行），未将供应商复权价用于任何信号计算。
