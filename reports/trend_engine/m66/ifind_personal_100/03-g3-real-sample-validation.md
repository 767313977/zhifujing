# M6.6 增补 Batch 3：G3 历史板块成分验证（iFinD 个人基础版）

- 日期：2026-11-16
- 批次：`ifind_personal_100_20261115T162631Z`
- 请求：6 次（2 次客户端指向错误 server 的失败请求 + 2 次 2025-03-05 截面 + 2 次 2026-09-28 截面）
- 结论：**iFinD 只能返回当前成分，不能返回历史截面 → G3 FAIL**

---

## 1. 实测结果

| 查询 | 样本 | 返回 | 总数 |
| --- | --- | --- | ---: |
| 芯片概念 2025-03-05 成分 | G3-C1-01 | `板块名称/证券代码/证券简称`，前 100 行 | 941 |
| 电力设备 2025-03-05 成分 | G3-I1-01 | 同上 | 418 |
| 芯片概念 2026-09-28 成分 | G3-C1-03 | 同上，前 100 行与 2025-03-05 **完全一致** | 941 |
| 电力设备 2026-09-28 成分 | G3-I1-03 | 同上，前 100 行与 2025-03-05 **完全一致** | 418 |

两次相隔 18 个月的查询返回**相同总数与相同前 100 行**（含相同的北交所代码顺序），说明 `sector_data` 忽略了历史日期参数，返回的是当前成分快照。

判定：`CURRENT_SNAPSHOT_ONLY`。

## 2. 失败请求说明

前 2 次 G3 请求把 `sector_data` 发到了 **stock** server，返回错误（该工具属于 index server）。这 2 次请求按规则计入预算（总计 6 次用于 G3 能力确认），不是供应商能力问题。修正 server 后 4 次全部成功。

## 3. 逐项能力

| 需求 | 结果 |
| --- | --- |
| 历史日期截面 | **不支持**（日期被忽略） |
| 当前成分名单 | 支持（单板块 941/418 条） |
| 成分纳入/剔除日期 | 不支持 |
| 退市证券历史成分 | 无法验证（当前快照不含历史） |
| 板块代码 / taxonomy | 仅板块名称，无代码、无分类体系标识 |
| 板块标准日 OHLCV | 不支持（`sector_data` 非日 K 工具） |
| 板块代码映射到 b1 | 无法建立（无代码、无官方映射表） |

## 4. G3 子门禁

| 子项 | 判定 | 依据 |
| --- | --- | --- |
| G3_HISTORICAL_SNAPSHOT | **FAIL** | 两个日期返回完全相同的当前成分 |
| G3_MEMBERSHIP_EVENTS | **FAIL** | 无 in/out 字段 |
| G3_DELISTED_COVERAGE | **UNKNOWN** | 当前快照无法验证历史退市证券 |
| G3_TAXONOMY_MAPPING | **UNKNOWN** | 只有名称，无代码/分类体系 |
| G3_REPEATABILITY | **PARTIAL** | 两次同板块不同日期返回一致，但这不是「同一查询重复」的严格复现 |
| G3_PERSONAL_LICENSE | **PARTIAL** | 用户授权个人研究测试；无书面许可 |
| G3_WEBSITE_LICENSE | **FAIL** | `WEBSITE_COMMERCIAL_LICENSE = NOT_ESTABLISHED` |
| **G3 总判定** | **FAIL** | 历史语义不成立，样本不可用于历史截面 |

## 5. 影响

- b1 的 374 个板块与外部体系映射仍未建立；iFinD 只给名称，无法生成可审计的 `provider_sector_id`。
- 如果继续用 iFinD 做「当前成分」校验，只能用于当期核对，**不能**回填 2025-03-05、2026-01-05 等历史日期（会违反「不得用当前快照反推历史」）。
- G3 的唯一可行路径仍是：Tushare `index_member_all`（申万，含 in/out）/ Choice `em_sector(isHistory=1)`，两者都需要新增授权。

## 6. 建议

1. 停止在 iFinD 上继续尝试历史成分（已用 6 次请求确认，符合「最多做必要确认」原则）。
2. 若用户希望推进 G3，需要批准 Tushare（6000 积分档）或 Choice 试用；否则 G3 保持 FAIL。
3. 当前成分可用于生成「映射候选」的名称对照，但必须标记 `CURRENT_SNAPSHOT_ONLY`，且不能进入 b1 映射表。
