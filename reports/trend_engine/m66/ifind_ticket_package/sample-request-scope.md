# iFinD 工单：随附样本说明（内部）

- 用途：向供应商说明「问题来自哪些真实返回」，不是投诉，也不是要数据
- 发送时**只挑选字段名与结构片段**，不附完整响应、不附账号信息

## 1. 三个样本（M6.4 真实调用）

| 样本 | 代码 | 事件 | 已观察到的字段行为 |
| --- | --- | --- | --- |
| 复权与现金分红 | 600519.SH | 除权 2026-06-26 | 「复权因子」由 8.6760 变为 8.8814；前复权与后复权收盘价落在同名列 |
| 送转 | 002594.SZ | 除权 2026-07-31 | 仅返回股权登记日、除权除息日、派息日与「进度」；送转比例为空 |

## 2. 公式核验结果（可提供给供应商）

- 用「不复权收盘价 × 复权因子」与接口返回的复权收盘价比较，600519 在除权日前后相对误差 ≤ **1.89bp**；
- 该结果只能说明「两者数值关系成立」，**不能说明因子方向与基准日**，因此仍需官方定义。

## 3. 发送时的信息安全规则

| 禁止附带 | 说明 |
| --- | --- |
| Token / Authorization / Cookie | 一律不提供 |
| 账号 ID、手机号、邮箱 | 一律不提供 |
| 内网地址、本地绝对路径 | 不提供 |
| 完整原始响应 | 只提供字段名与一两行结构示意 |
| 全市场或大样本数据 | 不提供 |

## 4. 我方期望的答复形式

1. 官方字段字典（字段名、含义、单位、方向、缺失值约定）；
2. 复权算法说明（单次因子、累计因子、基准日、修订规则）；
3. 每个接口一份**脱敏示例响应**；
4. 板块代码映射表（如有）；
5. 许可与配额说明（本地存储、衍生指标、网站展示、计量口径）。
