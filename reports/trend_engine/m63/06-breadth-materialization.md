# M6.3 Batch 5：breadth 离线物化

- 脚本：`scripts/m63_breadth_materialize.py`
- 证据：`breadth_full_coverage.csv`、`breadth_quality_report.json`
- 目标：把 `breadth_daily` 从「空表」变成**可复现的离线产物**，同时**不写任何原始数据库**。
- 结论：506/506 个交易日全部算出，SQL 与独立 Python 实现 3/3 抽样日完全一致；产物写入 sandbox。

---

## 1. 计算规则（沿用 M6.2，不得改动）

| 指标 | 规则 |
| --- | --- |
| 有效样本 | `close` 非空、`amount > 0`、`pct_chg` 非空 |
| 涨 / 跌 / 平 | `pct_chg > 0 / < 0 / == 0` |
| MA20 / MA60 | 该股实际交易行滚动均值，含当日，要求满窗口 |
| 上方均线 | `close > MA`，分母只含满窗口样本 |
| 20/60 日新高（低） | 收盘价等于（≥ / ≤）窗口内极值，窗口含当日 |
| 涨停/跌停（近似） | 300/301/688 → 19.8%；4/8/920 → 29.8%；其余 9.8% |
| ST | 无法识别，不剔除，质量状态 `APPROX_LIMIT_ST_UNKNOWN` |
