个人项目 · A 股复盘工具

致富经 个人自用的 A 股每日复盘与找票站点

收盘后自动把当天的行情、涨停、板块、资金数据采进本地 SQLite， 然后在浏览器里做复盘、按形态找票、记笔记。 这是给自己用的工具，不是产品 —— 没有多用户、没有权限体系，也不打算做成 SaaS。

GitHub 仓库 选池策略速查 跑起来

它能干什么

九个页面，覆盖「当天发生了什么 → 为什么 → 明天盯什么」这条链路。

今日复盘

指数卡片、成交额、涨跌家数、情绪温度、板块热力、涨停梯队、龙虎榜、复盘笔记。

涨停复盘

连板晋级率、涨停梯队、题材共振、首封时间分布，明细里带涨停原因。

情绪周期

近 60 日涨停数 / 炸板率 / 连板高度，叠加指数曲线看周期位置。

板块题材

板块排行与成分股、轮动矩阵、多板块强弱对比，以及板块资金流向与累计净流入曲线。

形态选股

全市场日线形态扫描（均线多头、N 日新高、平台突破、放量上涨…），命中可推送到飞书。

个股详情

概况、所属题材、日/周/月 K（蜡烛 + 均线 + 量）、资金流向 DDE、悟道阶段判定。

几个工程上的取舍

这些不是设计时想到的，是踩过坑之后改成的 —— 项目里有一份近万行的决策日志逐条记着。

配额是最稀缺的资源

数据源个人版有调用次数上限且账号级共享。用量到 80% / 90% / 95% 分三档让路：先停形态日线、再停概念兜底、最后只保指数与涨停三池这条主线。

免费源三级兜底

补日线走 东财 → 腾讯 → iFinD，前两级免费、失败即熔断切换， 正常日子零配额消耗。

复权口径不能含糊

库里存不复权价，区间收益一律按每日涨跌幅逐日复利算 —— 直接比收盘价， 除权那天会凭空多出一个 −30% 的假样本。

阈值必须带实测依据

每个关键阈值旁边都写着它是怎么定的、实测前后差多少，以及改动之后哪些历史数字不再可比。

选池策略

「明天盯 / 明天预案 / 洗完可盯 / 洗后可盯」等六个池子，每一个都写了 是什么、有什么证据、该怎么用、已知局限，含回测与线上成绩单的实际数字。 想直接用、或想知道某个池子值不值得看，先翻那一份。
